# 🚀 Running Locally

Clone the repository

```bash
git clone https://github.com/tehlil/New-portfolio.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Visit

```
http://localhost:3000
```
